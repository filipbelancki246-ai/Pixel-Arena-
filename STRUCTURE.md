# Структура проекта Pixel Arena Bot

```
pixel-arena-bot/
├── bot.py              ← Telegram-бот (Python). Запускаешь именно этот файл.
├── requirements.txt    ← список библиотек, которые нужно установить (aiogram)
├── README.md           ← пошаговая инструкция по запуску и деплою
├── STRUCTURE.md         ← этот файл
└── webapp/
    └── index.html      ← сама игра (Pixel Arena). Этот файл заливается
                           на хостинг (Vercel/GitHub Pages), бот на него
                           только ссылается.
```

## Как всё связано

```
Игрок в Telegram
      │
      │ пишет /start
      ▼
  bot.py (работает у тебя на компьютере/сервере,
          слушает сообщения через токен BotFather)
      │
      │ присылает кнопку "Играть"
      ▼
Кнопка открывает WEBAPP_URL ──► index.html
                                 (лежит отдельно, на хостинге,
                                  бот его не хранит и не запускает —
                                  просто знает ссылку на него)
```

Это два независимых, отдельно работающих куска:
- **bot.py** — общается с Telegram, ничего не знает про игровую логику.
- **index.html** — вся игра целиком (11 мини-игр, профиль, чат, лидерборд),
  работает у игрока в браузере (внутри Telegram WebView), бота вообще не трогает.

Они связаны только одной строкой — `WEBAPP_URL` внутри `bot.py`, которая
указывает, где лежит `index.html`.

## Файл bot.py — что внутри

| Часть кода                     | Что делает                                              |
|---------------------------------|----------------------------------------------------------|
| `BOT_TOKEN`, `WEBAPP_URL`        | твои настройки — токен от BotFather и ссылка на игру      |
| `cmd_start()`                    | ответ на `/start` — присылает кнопку "Играть"             |
| `cmd_play()`                     | ответ на `/play` — то же самое ещё раз                    |
| `cmd_help()`                     | ответ на `/help` — короткая справка                       |
| `play_keyboard()`                | рисует саму кнопку со ссылкой на Mini App                 |
| `setup_menu_button()`            | добавляет постоянную кнопку "Играть" у поля ввода          |

Бот не хранит данные игроков, не считает очки, не ведёт лидерборд — всё
это делает сама игра (`index.html`) на устройстве игрока.

## Файл webapp/index.html — что внутри

Один большой файл: HTML-разметка всех экранов + CSS-стили + весь JS
одним куском. Внутри — 11 игр (змейка, мемори, сапёр, шахматы, бильярд,
крестики-нолики, реверси, 2048, тетрис, виселица, платформер), профиль,
ачивки, лидерборд, чат. Изначально была страница логина по
ник+пароль — при адаптации под Telegram добавлен автовход через
`Telegram.WebApp.initDataUnsafe.user`, чтобы этот экран пропускался.

Прогресс хранится в `localStorage` браузера/WebView — то есть на
устройстве игрока, а не на сервере. Бэкенда и базы данных в проекте нет.

## Куда что добавлять дальше

- Хочешь новую команду бота (например, `/stats`) → правишь `bot.py`.
- Хочешь изменить саму игру (баланс, новый уровень, дизайн) → правишь
  `webapp/index.html` и перезаливаешь его на хостинг.
- Хочешь общий лидерборд между всеми игроками (не только личный рекорд)
  → это уже требует отдельного сервера с базой данных — в текущей
  структуре его нет, добавляется отдельным шагом.
